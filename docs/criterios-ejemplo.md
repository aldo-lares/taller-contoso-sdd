# Criterios de aceptación de ejemplo

- CUANDO un supervisor intente guardar una incidencia sin línea de producción, EL SISTEMA DEBE impedir el guardado.
- CUANDO la severidad sea Alta, EL SISTEMA DEBE mostrar la incidencia al inicio de la vista de incidencias abiertas.
- CUANDO un usuario con rol Supervisor intente cerrar una incidencia, EL SISTEMA DEBE impedirlo.
- CUANDO alguien cambie el estado a Cerrada, EL SISTEMA DEBE registrar la fecha de cierre.
